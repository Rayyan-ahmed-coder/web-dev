How this started

Our journey started when we realized many beginners
found coding confusing and boring. We wanted to create a
place where learning HTML, CSS and JavaScript felt exciting
and practical.

So our mission is to create a place where learning is simple and fun no matter
if you are a beginner or a pro.

We want to help and inspire the next generation of developers and
creators all around the would.
